# P5-B Institutional Pilot Route

P5-B may begin only after an institution separately approves a completed P5-A Validation Report and a bounded, non-public pilot charter.

1. **Pilot charter:** name a sponsoring institution, accountable owner, private-network boundary, permitted case types, retention policy, and explicit non-judicial/non-public constraints.
2. **Readiness gate:** verify an approved Registry of Record chain for every ML Provider, current calibration scope, P3-C deployment baseline, audit-chain checks, backup/restore drill, and reviewer-role separation.
3. **Shadow operation:** analyze a small, pre-authorized sample set without operational consequence. Compare reports and independent review decisions; retain all errors and abstentions.
4. **Governance review:** assess validation metrics, failure register, review agreement, security observations, and scope violations. Decide whether to continue, narrow scope, or halt.
5. **Pilot closeout:** issue an internal pilot report, archive evidence according to the charter, revoke temporary access, and document unresolved risks.

P5-B remains a controlled private pilot. It does not permit public access, commercial deployment, real government-system integration, judicial certification, or a public claim of AI-image detection accuracy.
