# P2-B2 entry plan

P2-B2 may begin only after explicit confirmation and at least one external image dataset has a signed-off registry entry and a verified local data index.

1. Materialise only approved data, verify each index content hash, and run label/split contamination tests.
2. Select one licensed encoder checkpoint, record its source, licence, checksum, version, feature dimension, and hardware before obtaining it.
3. Extract features offline into hash-bound experiment artifacts; do not train a final classifier or expose an API.
4. Run a small, documented baseline only after train/calibration/test split review.
5. Report coverage and failure modes privately as research evidence, without asserting AI detection capability.
